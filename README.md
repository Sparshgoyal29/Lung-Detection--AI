# SND Hospital - AI Lung Disease Detection System

An AI-powered web application that detects lung disease from Chest X-Ray images using Deep Learning and TensorFlow.

## Features

* Patient Registration Form
* Chest X-Ray Upload
* AI-based Disease Detection
* Confidence Score Prediction
* X-Ray Preview
* PDF Report Generation
* SQLite Database Storage
* Admin Dashboard
* Patient History Management

## Technologies Used

* Python
* Flask
* TensorFlow / Keras
* SQLite
* HTML
* CSS
* ReportLab

## Project Workflow

Patient Details → Upload X-Ray → AI Analysis → Report Generation → PDF Download → Database Storage → Dashboard
